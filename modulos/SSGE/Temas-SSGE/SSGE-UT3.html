1. El cambio de mentalidad: De Java a Python

Si vienes de programar en Java, lo primero que vas a notar al abrir un archivo de Python (que terminan en .py) es una sensación de ligereza total. Python fue creado con una regla de oro: el código debe leerse casi como si fuera inglés normal.

1.1. Las 4 cosas que desaparecen respecto a Java

  • Adiós al punto y coma (;): En Python cada línea es una orden. Para terminar una instrucción, simplemente pulsas Enter y pasas a la línea siguiente.
  • Adiós a la clase envolvente y al public static void main: No necesitas crear una clase solo para probar cuatro líneas de código. Escribes tus órdenes desde la línea 1 del archivo y Python las ejecuta de arriba abajo.
  • Adiós a las llaves { } en bloques: En lugar de usar llaves para saber qué está dentro de un if o de un bucle, Python te obliga a usar sangría (4 espacios hacia la derecha).
  • Adiós a declarar el tipo de las variables: No escribes String nombre ni int edad. Escribes directamente el nombre de la variable y Python deduce el tipo automáticamente.
Ejemplo 1: Tu primer programa (Comparativa visual)

Observa cuántas líneas necesitas en Java frente a Python para mostrar un mensaje por pantalla:

# --- EN JAVA (5 líneas obligatorias) ---

#         System.out.println("¡Bienvenido a la tienda de videojuegos!");
#     }

# --- EN PYTHON (1 sola línea) ---
print("¡Bienvenido a la tienda de videojuegos!")
2. Variables, Tipos de Datos e Interacción

Imagina que una variable es una caja donde guardas un dato. En Java tienes cajas exclusivas para números y cajas exclusivas para textos. En Python, la misma caja sirve para guardar cualquier cosa.

2.1. Los 4 tipos básicos que necesitas conocer

Tipo en Python Cómo se escribe Explicación para principiantes
Texto (str) juego = "Zelda" Puedes usar comillas dobles " " o simples ' ' indistintamente.
Entero (int) vidas = 3 Números sin decimales (positivos o negativos).
Decimal (float) precio = 59.99 Números con decimales (se usa siempre el punto ., nunca la coma).
Booleano (bool) conectado = True Solo puede ser True o False. ¡Ojo! La primera letra va SIEMPRE en mayúscula (en Java iba en minúscula).

2.2. Unir textos y variables: El truco de la letra "f" (f-strings)

En Java, para juntar texto y variables usabas el símbolo + (como "Tienes " + vidas + " vidas"), lo cual era incómodo. En Python, basta con poner una letra f antes de las comillas y meter las variables entre llaves { } directamente dentro de la frase:

personaje = "Mario"
monedas = 45
precio_vida = 12.50

# Ponemos una 'f' antes de abrir las comillas y metemos las variables entre { }
print(f"El jugador {personaje} tiene {monedas} monedas y cada vida cuesta {precio_vida} euros.")

2.3. Pedir datos al usuario por teclado con input()

Olvídate de crear un Scanner teclado = new Scanner(System.in). En Python usas directamente la palabra input(). Solo debes recordar una regla muy importante: input() siempre devuelve texto (str). Si vas a pedir un número para sumar o restar, debes envolverlo con int(...) o float(...):

# Pedir un texto normal
nombre_usuario = input("¿Cómo te llamas?: ")

# Pedir un número entero (envolvemos input con int para poder sumar con él)
anio_nacimiento = int(input("¿En qué año naciste?: "))

edad = 2026 - anio_nacimiento
print(f"Hola {nombre_usuario}, en 2026 cumples {edad} años.")
3. Tomar Decisiones: Condicionales y la Regla de la Sangría

Para que tu programa tome caminos distintos según una condición, usamos if (si ocurre esto...), elif (si no, pero ocurre esto otro...) y else (en cualquier otro caso).

3.1. ¿Cómo funciona la sangría (indentación)?

En Python, después de escribir la condición ponemos dos puntos :. Al pulsar Enter, todas las líneas que tengan 4 espacios a la izquierda (un tabulador) están dentro de ese bloque. Cuando vuelves a escribir pegado al margen izquierdo, el bloque se ha cerrado.

Ejemplo 2: Sistema de entrada a un cine según tu edad
edad = 16
tiene_carnet_joven = True

if edad < 12:
    print("Entrada infantil: 5 euros.")
    print("Regalo de palomitas pequeñas incluido.")
elif edad >= 12 and tiene_carnet_joven:
    print("Entrada joven con descuento: 6 euros.")
else:
    print("Entrada general de adulto: 9 euros.")

print("¡Disfruta de la película!") # Esta línea está fuera del if porque no tiene sangría

3.2. Operadores lógicos en inglés claro

En vez de símbolos raros como en Java, en Python escribes las palabras directamente en inglés:

  • En lugar de && se escribe and (se tienen que cumplir las dos cosas).
  • En lugar de || se escribe or (basta con que se cumpla una de las dos).
  • En lugar de ! se escribe not (invierte el valor: si algo es verdad, pasa a falso).
4. Repetir Tareas: Bucles for y while

Cuando quieres repetir una acción varias veces o recorrer una colección de datos, dispones de dos herramientas muy simples.

4.1. El bucle for con range() (Para contar números)

Si quieres repetir algo un número determinado de veces, usas range(n). Ten en cuenta que Python siempre empieza a contar desde el 0 y se detiene justo antes del número que le digas:

# Repetir algo 3 veces (i valdrá 0, luego 1 y luego 2)
for i in range(3):
    print(f"Intento número {i}")

# También puedes decirle desde qué número hasta qué número contar: range(inicio, fin_sin_incluir)
for nivel in range(1, 4):
    print(f"Superando el nivel {nivel}...") # Imprime los niveles 1, 2 y 3

4.2. El bucle while (Repetir mientras se cumpla una condición)

Funciona exactamente igual que en Java: mientras la condición sea verdadera, sigue dando vueltas.

bateria = 30

while bateria > 0:
    print(f"Jugando... Batería restante: {bateria}%")
    bateria -= 10  # Restamos 10 en cada vuelta (en Python no existe el operador ++)

print("El móvil se ha apagado.")
5. Guardar Colecciones de Datos: Listas, Tuplas y Diccionarios

Aquí es donde Python brilla de verdad frente a Java. No tienes que importar librerías complejas para crear listas o mapas; todo se hace usando tres tipos de símbolos: corchetes [ ], paréntesis ( ) y llaves { }.

5.1. Las Listas [ ] (Tu carrito de la compra modificable)

Una lista equivale a un ArrayList de Java. Guarda varios elementos en orden, empezando en la posición 0. Puedes añadir cosas nuevas, borrar o cambiar las que ya hay:

# 1. Crear una lista con corchetes [ ]
mochila = ["Espada", "Escudo", "Poción"]

# 2. Leer elementos por su posición
print(mochila[0])   # Imprime "Espada" (el primero)
print(mochila[-1])  # Truco de Python: el -1 SIEMPRE te da el último elemento ("Poción")

# 3. Añadir un objeto nuevo al final con .append()
mochila.append("Arco")

# 4. Saber cuántas cosas hay dentro con len()
print(f"Llevas {len(mochila)} objetos en la mochila.")

# 5. Recorrer la lista directamente con un bucle for (sin necesitar índices)
for objeto in mochila:
    print(f"- Tienes equipado: {objeto}")

5.2. Las Tuplas ( ) (Cajas precintadas que no se pueden tocar)

Se escriben con paréntesis ( ). Son idénticas a las listas, con una única diferencia: son inmutables (una vez creadas, nadie puede cambiar ni borrar sus datos por accidente). Además, permiten un truco llamado desempaquetado para guardar cada dato en una variable de golpe:

# Una tupla con las coordenadas de un tesoro y el nombre de la isla
ubicacion = (40, -3, "Isla Calavera")

# Desempaquetado: repartimos los 3 datos en 3 variables en una sola línea
latitud, longitud, nombre_isla = ubicacion

print(f"El tesoro de {nombre_isla} está en ({latitud}, {longitud})")

5.3. Los Diccionarios { } (Fichas con etiquetas Clave : Valor)

Imagina la ficha de un alumno o un producto de Amazon. En vez de buscar los datos por su posición (posición 0, posición 1...), les pones una etiqueta con nombre (clave) y su dato (valor) separados por dos puntos :.

# Creamos la ficha de un coche usando llaves { }
coche = {
    "marca": "Toyota",
    "modelo": "Supra",
    "caballos": 340,
    "en_venta": True
}

# Leer un dato usando su etiqueta entre corchetes
print(coche["marca"])  # Imprime: Toyota

# Modificar un dato existente o añadir una etiqueta nueva es igual de fácil:
coche["caballos"] = 380          # Cambiamos los caballos de 340 a 380
coche["color"] = "Rojo brillante" # Añadimos una etiqueta nueva al diccionario
6. Trucos Muy Útiles de Python (Recortar textos y Funciones)

6.1. El "Slicing" o Rebanado: Cortar textos como un pan de molde

Si tienes un texto largo (como una matrícula, un DNI o una fecha) y quieres extraer solo un trozo, en Python usas corchetes indicando [desde_donde : hasta_donde_sin_incluir]:

codigo_vuelo = "IB-3489-MAD"
# Posiciones:   0123456789...

compania = codigo_vuelo[0:2]  # Corta desde la posición 0 hasta la 2 -> "IB"
numero   = codigo_vuelo[3:7]  # Corta desde la posición 3 hasta la 7 -> "3489"
destino  = codigo_vuelo[8:11] # Corta desde la posición 8 hasta la 11 -> "MAD"

print(f"Vuelo {numero} de {compania} con destino a {destino}")

6.2. Crear tus propias Funciones con def

Para no repetir código, puedes crear tus propias órdenes reutilizables usando la palabra clave def (de definir):

# Definimos una función que calcula el precio final con el 21% de IVA
def calcular_con_iva(precio_sin_iva):
    total = precio_sin_iva * 1.21
    return round(total, 2)  # round(..., 2) redondea a 2 decimales

# Ahora podemos usar nuestra función todas las veces que queramos:
precio_teclado = calcular_con_iva(40)
precio_monitor = calcular_con_iva(150)

print(f"El teclado con IVA cuesta {precio_teclado}€ y el monitor {precio_monitor}€")
7. Proyecto Práctico Completo: Gestor de una Tienda de Informática

Para ver cómo encajan todas las piezas juntas en un caso de la vida real, imagina que tienes una tienda de informática con una lista de productos (una lista de diccionarios) y quieres analizar tu inventario automáticamente:

Código Completo Explicado Línea a Línea: tienda.py
# 1. Creamos nuestro catálogo: una LISTA [ ] que contiene DICCIONARIOS { }
catalogo = [
    {"nombre": "Ratón Gaming", "categoria": "Periféricos", "precio": 25.50, "stock": 12},
    {"nombre": "Teclado Mecánico", "categoria": "Periféricos", "precio": 65.00, "stock": 0},
    {"nombre": "Monitor 27 pulgadas", "categoria": "Pantallas", "precio": 199.99, "stock": 4},
    {"nombre": "Alfombrilla XL", "categoria": "Periféricos", "precio": 12.00, "stock": 20}
]

# OBJETIVO 1: Mostrar qué productos están agotados (stock igual a 0)
print("--- 1. PRODUCTOS AGOTADOS ---")
for prod in catalogo:
    if prod["stock"] == 0:
        print(f"¡Alerta! Hay que pedir más unidades de: {prod['nombre']}")

# OBJETIVO 2: Calcular cuánto dinero cuestan todos los "Periféricos" juntos
print("\n--- 2. SUMA DE PRECIOS DE PERIFÉRICOS ---")
suma_perifericos = 0

for prod in catalogo:
    if prod["categoria"] == "Periféricos":
        suma_perifericos += prod["precio"]

print(f"Comprar un periférico de cada cuesta en total: {suma_perifericos} €")

# OBJETIVO 3: Truco pro de Python -> Sumar el stock total de toda la tienda en 1 sola línea
total_unidades = sum(prod["stock"] for prod in catalogo)
print(f"\n--- 3. UNIDADES TOTALES EN EL ALMACÉN: {total_unidades} unidades ---")

8. Estructura Básica y Ejecución en «Operación Bóveda» (Lección 01)

En Java, para mostrar un simple mensaje por pantalla necesitas crear una clase public class..., abrir llaves, declarar public static void main(String[] args) y escribir System.out.println() terminado en punto y coma. En Python todo eso desaparece: escribes directamente las órdenes una debajo de otra.

8.1. Las 4 Reglas de Oro frente a Java

  • Sin clases ni método main obligatorios: El archivo empieza a ejecutarse directamente desde la primera línea de arriba hacia abajo.
  • Sin punto y coma (;): El final de una línea marca el final de la instrucción.
  • Sin compilación previa manual: No hay que generar un archivo intermedio antes de probarlo; el intérprete lee y ejecuta tu archivo .py directamente.
  • Comentarios con almohadilla (#): Todo lo que escribas después de # en una línea es un comentario (equivale al // de Java).
# En Java: System.out.println("Hola");
# En Python basta con escribir esta única línea en el archivo hola.py:
print("Hola")

8.2. Cómo ejecutar tu programa y estructura de la práctica

  • Ejecución desde terminal: Abres la consola en la carpeta de tu archivo y escribes python hola.py (o py hola.py si estás en Windows).
  • Organización en «Operación Bóveda»: Trabajamos con dos ficheros en la misma carpeta:

    • mision.py: Es tu archivo de trabajo donde programas las soluciones y el que ejecutas en la terminal.

10. Condicionales, Bucles y Colecciones de «Operación Bóveda» (Lecciones 03 a 06)

10.1. Condicionales y método startswith() (Lección 03)

  • Palabras clave: Se usa if (si), elif (equivale al else if de Java) y else (sino), cerrados por dos puntos (:) y con 4 espacios de sangría.
  • Operadores lógicos: En lugar de &&, ||, !, se escriben en inglés: and, or, not.
  • Comparar textos: En lugar de texto.equals("..."), usas directamente == tanto para números como para textos.
  • Comprobar cómo empieza un texto: El método ip.startswith("10.") devuelve True si la cadena guardada en ip empieza por "10.".
ip = "185.220.101.47"

# Fíjate en los dos puntos (:) al final de cada condición y en los 4 espacios de sangría:
if ip.startswith("10."):
    print("Es una IP de la red interna")
elif ip == "":
    print("La dirección IP está vacía")
else:
    print("¡Alerta! Es una IP externa")

# Ejemplo con operadores lógicos en inglés (not, and, or):
if not ip.startswith("10."):
    print("Confirmado: el acceso NO viene de la red local 10.x")

10.4. Diccionarios e Importación de Módulos (Lección 06)

  • Importar datos de otro archivo: Para traer las listas guardadas en datos.py a tu programa, escribes arriba del todo: from datos import empleados, accesos.
  • Tablas en memoria (Listas de diccionarios): Varios diccionarios dentro de una lista [ {...}, {...} ] conforman una tabla completa donde cada diccionario es la ficha de un empleado.
  • Sumar datos en una sola línea con sum(): Permite sumar un campo de todos los diccionarios de una lista directamente: sum(e["salario"] for e in empleados).
from datos import empleados

# Así es un diccionario individual (una ficha de un empleado):
e = {"id": 6, "nombre": "Raúl Quintero", "depto": "Ventas", "salario": 2950}

print(e["nombre"])   # Leemos el valor de la etiqueta "nombre" -> Raúl Quintero
e["salario"] = 3000  # Modificamos el salario directamente por su etiqueta

# Recorremos la lista de diccionarios 'empleados' para filtrar los del depto "Sistemas":
for e in empleados:
    if e["depto"] == "Sistemas":
        print(e["nombre"], "cobra:", e["salario"])

# Sumamos todos los salarios de la empresa en una sola línea:
total_nominas = sum(e["salario"] for e in empleados)
print("Gasto total en nóminas:", total_nominas)
11. Práctica Resuelta Paso a Paso: Misiones 1 a 7 (Operación Bóveda)

12. Funciones: Métodos sin Clase y Parámetros por Defecto (Lección 01)

En Python las funciones se declaran con la palabra clave def sin necesidad de pertenecer a una clase ni especificar tipos de retorno o de argumentos. Además, en lugar de sobrecargar métodos como en Java, los parámetros opcionales se resuelven directamente asignándoles valores por defecto.

En Java (Sobrecarga y tipos explícitos) En Python (Sin tipos, sin clase y valores por defecto) 
public static int doble(int n) {
    return n * 2;
}

// Sobrecarga para parámetros
// opcionales: varios métodos
 
def doble(n):
    return n * 2

def saludar(nombre, cargo="agente"):
    return f"Hola, {cargo} {nombre}"

print(saludar("Vega"))                # Hola, agente Vega
print(saludar("Vega", cargo="jefa"))  # Hola, jefa Vega
13. Ficheros de Texto: Abrir, Leer y Cerrar con with (Lección 02)

Para trabajar con archivos en Python se emplea la sentencia with open(...) as f:, que garantiza que el fichero se cierre automáticamente al terminar el bloque (exactamente igual que el try-with-resources de Java), incluso si ocurre un error.

# Lectura línea a línea
with open("notas.txt", encoding="utf-8") as f:
    for linea in f:
        print(linea.strip())  # .strip() elimina saltos de línea y espacios sobrantes

# Escritura en fichero (sobrescribe si ya existe)
with open("salida.txt", "w", encoding="utf-8") as f:
    f.write("Caso cerrado\n")
Reglas clave para el manejo de ficheros
  • Cierre automático: with cierra el fichero solo (como try-with-resources).
  • Modos de apertura: "r" leer (por defecto si no se indica), "w" escribir (sobrescribe), "a" añadir al final (append) y "x" crear nuevo (falla si ya existe).
  • Codificación en Windows: Usa siempre encoding="utf-8" para evitar problemas con tildes y la letra ñ.
14. Ficheros CSV: Una Fila, un Diccionario (Lección 03)

El módulo integrado csv permite leer tablas separadas por comas (o punto y coma) convirtiendo automáticamente cada fila en un diccionario mediante csv.DictReader(f), usando la primera fila de cabecera como claves.

import csv

with open("clientes.csv", encoding="utf-8") as f:
    clientes = list(csv.DictReader(f))

print(clientes[0]["nombre"])  # Ferretería Ortega

# Convertimos a int() porque en CSV todo llega como texto
total = sum(int(c["facturacion"]) for c in clientes)
¡OJO! Detalles críticos al leer CSV
  • Todo valor del CSV llega como texto (str): Si necesitas sumar importes o comparar números, recuerda convertirlos explícitamente con int(...) o float(...).
  • Celdas vacías: Un campo vacío se lee como cadena vacía "" y en Python evalúa como falso (falsy) dentro de un if (por ejemplo, if c["ciudad"]: será False si está vacío).
15. Ficheros JSON: De Fichero a Diccionario y List Comprehension (Lección 04)

El módulo nativo json traduce de forma directa la estructura de un archivo .json a listas y diccionarios de Python (json.load()) y viceversa (json.dump()).

import json

# 1. Leer JSON a lista de diccionarios
with open("pedidos.json", encoding="utf-8") as f:
    pedidos = json.load(f)  # Devuelve directamente una lista de dicts

# 2. Filtrar con comprensión de listas (List Comprehension)
pendientes = [p for p in pedidos if p["estado"] == "pendiente"]

# Equivale al bucle tradicional:
# pendientes = []
# for p in pedidos:
#     if p["estado"] == "pendiente":
#         pendientes.append(p)

# 3. Guardar datos en un nuevo fichero JSON legible y con tildes
with open("pendientes.json", "w", encoding="utf-8") as f:
    json.dump(pendientes, f, indent=2, ensure_ascii=False)
  • indent=2: Escribe el JSON formateado y sangrado con 2 espacios, un dato por línea. Sin este parámetro, todo se guardaría en una única línea ilegible.
  • ensure_ascii=False: Conserva las tildes y caracteres especiales tal cual (por ejemplo "Logística"). Sin él, se escaparían como códigos Unicode ("Log\u00edstica").
16. Control de Excepciones: try / except / finally (Lección 05)

En Python la estructura de control de errores sustituye la palabra catch de Java por except, manteniendo idéntico el funcionamiento de try y finally.

En Java (try / catch) En Python (try / except / finally) 
try {
    leer("clientes.csv");
} catch (IOException e) {
    System.out.println("Sin fichero");
}
 
try:
    clientes = cargar("clientes.csv")
except FileNotFoundError:
    print("Sin fichero")
finally:
    print("Fin de la lectura")
