Manejo de Ficheros XML y JSON: Procesamiento con DOM - SAX - XStream - Gson

1. Trabajo con Ficheros XML

Definición y Naturaleza: XML (eXtensible Markup Language) es un metalenguaje, es decir, un lenguaje pensado para la definición de lenguajes de marcado. Permite jerarquizar y describir semánticamente los contenidos dentro del propio documento.

Organización de los Datos: Los ficheros XML organizan la información de manera secuencial y en estricto orden jerárquico (relaciones de árbol: padres, hijos, hermanos, ascendientes y descendientes).

Principales Casos de Uso:

  • Alimentar y proporcionar datos de entrada a bases de datos relacionales o estructuradas.
  • Almacenar información en bases de datos especiales orientadas a documentos.
  • Ficheros de configuración de aplicaciones y entornos de despliegue.
  • Intercambio de datos e interoperabilidad en servicios web (como el protocolo SOAP).
  • Ejecución e invocación de comandos en servidores y sistemas remotos.

Procesadores XML (Parsers): Como XML no es un lenguaje Turing completo, requiere de un lenguaje de programación anfitrión (como Java) para dotarlo de lógica operativa. Para leer, analizar y modificar la estructura de estos archivos se emplea un XML parser, siendo los más utilizados DOM y SAX.

Representación textual: Anatomía y Estructura Jerárquica de un Fichero XML

Componentes sintácticos:

  • Prólogo XML: Declaración inicial que define la versión de especificación empleada (ej.: <?xml version="1.0"?>).
  • Elemento Raíz: Nodo contenedor único del que descienden todos los demás (ej.: <raíz> ... </raíz>).
  • Elementos Hijos y Contenido: Nodos anidados que contienen texto u otros subelementos (ej.: <elemento1>, <elemento2>Contenido</elemento2>).
  • Atributos: Pares clave-valor insertados en la etiqueta de apertura para aportar metadatos al nodo (ej.: <elemento11 atributo="contenido atributo">).

Estructura en Árbol: Nodo raíz superior conectado a nodos intermedios ramificados que culminan en nodos hoja con el contenido textual o de datos.

2. Acceso a Ficheros con DOM (Document Object Model)

Características Principales:

  • DOM es el estándar oficial definido por el W3C para trabajar con documentos estructurados XML.
  • Carga y almacena toda la estructura jerárquica del documento completa en la memoria principal (RAM) en forma de árbol de nodos navegable.
  • Permite navegación bidireccional, lectura aleatoria y modificación total en memoria, pero exige significativamente más memoria y tiempo de procesamiento que enfoques basados en eventos.

Paquetes de Java Empleados:

  • org.w3c.dom: Contiene las interfaces centrales del modelo de nodos del JSDK.
  • javax.xml.parsers: Provee las fábricas y constructores DocumentBuilderFactory y DocumentBuilder del API estándar de Java.
  • javax.xml.transform: DOM por sí mismo no define cómo volcar un árbol a disco; este paquete permite transformar y escribir fuentes (Source) en destinos (Result), como ficheros o flujos.

Tabla: Interfaces Fundamentales de org.w3c.dom

Interfaz Función y Descripción
Document Representa el documento XML al completo en memoria; actúa como fábrica para crear nuevos nodos y elementos.
Element Representa de manera específica cada uno de los elementos o etiquetas del documento.
Node Interfaz base de la jerarquía que representa cualquier tipo de nodo genérico del árbol.
NodeList Colección indexada ordenada que almacena una lista con los nodos hijos obtenidos de una consulta.

3. Programación con DOM: Escritura y Lectura en Java

3.1. Escritura y Generación de Ficheros XML con DOM

El procedimiento técnico para construir y persistir un XML con DOM requiere cuatro pasos fundamentales:

  • 1. Inicialización del Documento: Crear una factoría DocumentBuilderFactory, instanciar el DocumentBuilder y obtener el DOMImplementation para crear un documento vacío asignando el elemento raíz y la versión XML.
  • 2. Construcción del Árbol de Elementos: Crear elementos con createElement(), nodos de texto con createTextNode() y ensamblarlos mediante llamadas sucesivas a appendChild().
  • 3. Transformación y Serialización: Instanciar un Transformer desde TransformerFactory, vinculando una fuente DOM (DOMSource) con un destino de flujo o archivo (StreamResult).
  • 4. Salida por Pantalla: Es posible redirigir la misma transformación hacia la salida estándar usando new StreamResult(System.out).
Código Ejemplo: Creación y Volcado de XML con DOM
// 1. Instanciamos la factoría y el builder
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = dbf.newDocumentBuilder();
DOMImplementation implementacion = builder.getDOMImplementation();
Document registroEmpleados = implementacion.createDocument(null, "empleados", null);
registroEmpleados.setXmlVersion("1.0");

// 2. Creación y adición de nodos de datos
Element empleado = registroEmpleados.createElement("empleado");
registroEmpleados.getDocumentElement().appendChild(empleado);

Element id = registroEmpleados.createElement("id");
Text textoId = registroEmpleados.createTextNode("01");
id.appendChild(textoId);
empleado.appendChild(id);

Element nombre = registroEmpleados.createElement("nombre");
Text textoNombre = registroEmpleados.createTextNode("Antonio");
nombre.appendChild(textoNombre);
empleado.appendChild(nombre);

// 3. Volcado del documento a disco con Transformer
Source origen = new DOMSource(registroEmpleados);
Result resultado = new StreamResult(new File("Empleados.xml"));
Transformer transformador = TransformerFactory.newInstance().newTransformer();
transformador.transform(origen, resultado);

3.2. Lectura y Procesamiento de Ficheros XML con DOM

Para procesar un documento existente mediante DOM se siguen las siguientes fases operativas:

  • Carga y Parseo: Se instancia el DocumentBuilder y se invoca el método builder.parse(new File("archivo.xml")), cargando todo el árbol en memoria.
  • Normalización: Se aplica normalize() sobre el elemento raíz para unir nodos de texto contiguos y asegurar una estructura uniforme de lectura.
  • Extracción y Recorrido: Mediante getElementsByTagName("etiqueta") se extrae un objeto NodeList; se itera sobre la lista recuperando cada Node con item(i), verificando que sea de tipo Node.ELEMENT_NODE para extraer los datos con getTextContent().
Código Ejemplo: Lectura y Procesamiento de Ficheros XML con DOM
// 1. Instanciamos la factoría y el builder para cargar el parser
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
DocumentBuilder builder = dbf.newDocumentBuilder();

// 2. Leemos y parseamos el documento XML desde disco
Document registroEmpleados = builder.parse(new File("Empleados.xml"));

// 3. Normalizamos el documento para estructurar el árbol y evitar fallos de lectura
registroEmpleados.getDocumentElement().normalize();

// Mostramos el nombre del elemento raíz
System.out.println("El elemento raíz es: " + 
    registroEmpleados.getDocumentElement().getNodeName());

// 4. Obtenemos la lista con todos los nodos 'empleado'
NodeList empleados = registroEmpleados.getElementsByTagName("empleado");
System.out.println("Se han encontrado " + empleados.getLength() + " empleados");

// 5. Recorremos el NodeList y procesamos cada elemento
for (int i = 0; i < empleados.getLength(); i++) {
    Node emple = empleados.item(i);
    
    // Comprobamos que el nodo sea de tipo elemento (etiqueta)
    if (emple.getNodeType() == Node.ELEMENT_NODE) {
        Element empleado = (Element) emple;
        
        // Extraemos y mostramos el valor de cada subetiqueta
        String id = empleado.getElementsByTagName("id").item(0).getTextContent();
        String nombre = empleado.getElementsByTagName("nombre").item(0).getTextContent();
        String apellido = empleado.getElementsByTagName("apellido").item(0).getTextContent();
        
        System.out.print("ID: " + id);
        System.out.print("\tNombre: " + nombre);
        System.out.println("\tApellido: " + apellido);
    }
}
4. Acceso a Ficheros con SAX (Simple API for XML)

Características Principales:

  • SAX es un API orientado a eventos que procesa el flujo del documento XML de forma secuencial línea a línea.
  • A diferencia de DOM, no carga todo el documento en memoria principal, reduciendo drásticamente el consumo de RAM.
  • Es la solución óptima para procesar archivos XML de gran volumen o cuando solo se precisa extraer información puntual.
  • Su API viene completamente integrada dentro del JRE estándar de Java.
  • Desventaja: Es más complejo de programar y requiere diseñar manejadores de eventos personalizados con variables de estado, ya que no permite navegar hacia atrás en el árbol.

Eventos Principales durante el Parseo con SAX

Método de Evento Disparador / Momento en el que se ejecuta
startDocument() Se dispara al detectar el inicio del documento XML (prólogo).
endDocument() Se ejecuta una vez alcanzado el final absoluto del documento.
startElement(...) Se activa cada vez que el analizador encuentra una etiqueta de apertura de un elemento.
endElement(...) Se notifica cuando el procesador encuentra la etiqueta de cierre correspondiente.
characters(...) Permite leer el contenido textual (caracteres) ubicado dentro de un elemento.
Manejadores Especializados en SAX (Interfaces de XMLReader)
  • ContentHandler: Recibe las notificaciones de los eventos sintácticos del contenido del documento.
  • DTDHandler: Recoge los eventos vinculados al procesamiento de definiciones DTD.
  • ErrorHandler: Define los métodos específicos para la captura y gestión de errores de validación sintáctica.
  • EntityResolver: Se invoca cada vez que se detecta una referencia a una entidad externa.
  • DefaultHandler: Clase base que implementa por defecto todas las interfaces anteriores; el desarrollador hereda de ella y solo sobrescribe los métodos necesarios.

4.1. Implementación de un Manejador Personalizado (AlumnosReader)

Código Ejemplo: Implementación de un Manejador Personalizado (AlumnosReader)
public class AlumnosReader extends DefaultHandler {
    @Override
    public void startDocument() throws SAXException {
        System.out.println("Inicio del documento");
    }

    @Override
    public void endDocument() throws SAXException {
        System.out.println("Fin del documento");
    }

    @Override
    public void startElement(String uri, String localName, String qName, Attributes attributes) {
        System.out.printf("\t Inicio del Elemento: %s \n", qName);
    }

    @Override
    public void endElement(String uri, String localName, String qName) {
        System.out.printf("\t Final del Elemento: %s \n", qName);
    }

    @Override
    public void characters(char[] ch, int start, int length) {
        String car = new String(ch, start, length).replaceAll("[\t\n]", "");
        if (!car.trim().isEmpty()) {
            System.out.printf("\t Valor del Elemento: %s \n\n", car);
        }
    }
}

4.2. Flujo de Ejecución Principal con SAX

Los pasos para procesar un archivo con SAX se resumen en cuatro acciones secuenciales:

  1. Crear una factoría SAXParserFactory y obtener la instancia del parser SAXParser.
  2. Obtener el analizador XMLReader e invocar setContentHandler(new AlumnosReader()) vinculando el manejador.
  3. Crear la fuente de datos mediante un objeto InputSource apuntando al archivo XML.
  4. Lanzar el parseo secuencial mediante procesadorxml.parse(xmlFile) gestionando las excepciones correspondientes.
Código Ejemplo: Flujo de Ejecución Principal con SAX
import javax.xml.parsers.ParserConfigurationException;
import javax.xml.parsers.SAXParser;
import javax.xml.parsers.SAXParserFactory;
import org.xml.sax.InputSource;
import org.xml.sax.SAXException;
import org.xml.sax.XMLReader;
import java.io.IOException;

public class ReaderSAX {
    public static void main(String[] args) {
        try {
            // 1. Creamos la factoría y el parser SAX
            SAXParserFactory parserFactory = SAXParserFactory.newInstance();
            SAXParser parser = parserFactory.newSAXParser();
            
            // 2. Obtenemos el XMLReader y le asignamos nuestro manejador (ContentHandler)
            XMLReader procesadorxml = parser.getXMLReader();
            procesadorxml.setContentHandler(new AlumnosReader());
            
            // 3. Definimos la fuente de datos (el fichero XML a leer)
            InputSource xmlFile = new InputSource("./alumnos.xml");
            
            // 4. Iniciamos el parseo secuencial del fichero
            procesadorxml.parse(xmlFile);
            
        } catch (SAXException | IOException e) {
            e.printStackTrace();
        } catch (ParserConfigurationException e) {
            e.printStackTrace();
        }
    }
}
5. Cuadro Comparativo: DOM vs. SAX
Criterio de Análisis Modelo DOM (Tree-Based) Modelo SAX (Event-Driven)
Modelo de Datos Árbol en memoria (jerarquía completa de nodos). Flujo de eventos unidireccional y secuencial.
Consumo de Memoria Alto; proporcional al tamaño total del archivo. Muy bajo y constante; no almacena el árbol en RAM.
Velocidad y Acceso Acceso aleatorio bidireccional ágil una vez cargado. Lectura secuencial rápida en un solo paso hacia adelante.
Capacidad de Edición Permite crear, modificar, reordenar y eliminar nodos. Solo lectura; no permite modificar el XML directamente.
Escenario Idóneo Documentos pequeños o medianos que requieren edición. Documentos XML masivos o consultas rápidas de datos.

Manejo de Ficheros XML con Objetos (Librería XStream)

1. Configuración e Instalación de XStream

Para serializar objetos Java a formato XML de forma sencilla, se emplea la librería externa XStream.

  • Descarga: Es necesario descargar la distribución binaria (ej. xstream-distribution-1.4.20-bin.zip) desde http://x-stream.github.io/download.html.
  • Librerías requeridas (JARs): Se deben extraer e importar al proyecto dos archivos principales:
    • xstream-1.4.20.jar (ubicado en la carpeta lib).
    • kxml2-min-2.3.0.jar (analizador sintáctico ligero tipo pull, ubicado también en lib/xstream).
  • Configuración en el IDE: Añadir estos JARs al Build Path del proyecto (en Eclipse: Project Properties → Java Build Path → Libraries → Classpath → Add JARs).
2. Preparación de Clases de Datos

Para generar un XML jerárquico a partir de múltiples objetos, se define una clase contenedora que agrupe una lista de instancias del modelo base (en este caso, Contacto).

Código: ListaContactos.java
import java.util.ArrayList;
import java.util.List;

public class ListaContactos {
    private List<Contacto> lista = new ArrayList<Contacto>();

    public ListaContactos() { }

    public void add(Contacto con) {
        lista.add(con);
    }

    public List<Contacto> getListaContactos() {
        return lista;
    }
}
3. Serialización: Convertir Objeto a XML

3.1. Inicialización y Configuración de Etiquetas

Para crear el motor conversor y formatear el XML resultante se instancian clases del paquete com.thoughtworks.xstream.*.

  • Instanciación: XStream xstream = new XStream(new DomDriver("UTF-8")); (Fuerza el uso de DOM con codificación UTF-8). Si se usa new XStream() sin parámetros, usará el parser por defecto (KXML).
  • Alias de Etiquetas: Cambia el nombre por defecto de los nodos XML (que coinciden con el nombre de la clase) usando alias():
    xstream.alias("DatosContacto", Contacto.class);
  • Ocultar Colecciones Implícitas: Evita que aparezca una etiqueta extra para envolver el atributo lista de la clase contenedora:
    xstream.addImplicitCollection(ListaContactos.class, "lista");
  • Omitir Campos: Excluye atributos específicos para que no se vuelquen al XML:
    xstream.omitField(Contacto.class, "telefono");
  • Generación del Archivo: xstream.toXML(objeto, OutputStream).
Código: Extracción desde Binario y Volcado a XML
public static void CrearFicheroXML() {
    File fichero = new File("contactos.dat");
        
        if (!fichero.exists()) {
            System.out.println("No existe el fichero " + fichero.getName());
        } else {
            ListaContactos listaContactos = new ListaContactos();
            ObjectInputStream ois = null;
            
            try {
                FileInputStream fis = new FileInputStream(fichero);
                ois = new ObjectInputStream(fis);
                
                System.out.println("Se esta leyendo el fichero...");
                
                while (true) {
                    Contacto c = (Contacto) ois.readObject();
                    listaContactos.add(c);
                }
            } catch (EOFException e) {
            } catch (FileNotFoundException e) {
                System.out.println("ERROR-1");
            } catch (IOException e) {
                System.out.println("ERROR-2");
            } catch (ClassNotFoundException e) {
                System.out.println("ERROR-3");
            } finally {
                try {
                    if (ois != null) {
                        ois.close();
                    }
                } catch (IOException e) {
                    System.out.println("Error al cerrar el flujo");
                }
            }
            
            try {
                XStream xstream = new XStream(new DomDriver("UTF-8"));
        
                xstream.alias("DatosContacto", Contacto.class);
                xstream.alias("Contactos", ListaContactos.class);
        
                xstream.addImplicitCollection(ListaContactos.class, "listaCont");
                xstream.omitField(Contacto.class, "numeroTelefono");
        
                xstream.toXML(listaContactos, new FileOutputStream("Contactos.xml"));
            } catch (IOException e) {
                System.out.println("ERROR-1");
            }
        }
    }
4. Deserialización: Leer de XML a Objeto

Para recuperar los datos, se requiere instanciar XStream y aplicarle la misma configuración de alias y colecciones implícitas que se usó al escribir. La lectura en sí se realiza mediante el método fromXML().

Código: Lectura del Archivo XML
public static void LeerXML() {
    XStream xstream = new XStream(new DomDriver("UTF-8"));
        
        xstream.addPermission(AnyTypePermission.ANY);
        xstream.alias("DatosContacto", Contacto.class);
        xstream.alias("Contactos", ListaContactos.class);
        xstream.addImplicitCollection(ListaContactos.class, "listaCont");
        
        try {
            ListaContactos contactos = (ListaContactos) xstream.fromXML(new FileInputStream("Contactos.xml"));
            System.out.println("Numeros de contactos: " + contactos.getListaContactos().size());
            List listaContactos = contactos.getListaContactos();
            
            ListIterator iterator = listaContactos.listIterator();
            while (iterator.hasNext()) {
                Contacto c = (Contacto) iterator.next();
                System.out.println("Nombre: " + c.getNombre() + ", apellidos: " 
                + c.getApellidos() + ", email: " + c.getEmail());
            }
            System.out.println("Fin del listado");
        } catch (FileNotFoundException e) {
            System.out.println("ERROR-1");
        }
    }

Manejo de Objetos JSON (Librería GSON)

1. Introducción a JSON y GSON

JSON (JavaScript Object Notation): Es un estándar abierto basado en texto plano diseñado para codificar información bajo un formato simple de atributo-valor. JSON es una alternativa altamente eficiente a XML y destaca fundamentalmente por su gran simplicidad para interactuar con arrays y objetos de manera directa.

Librería GSON: Google Gson es la librería open-source utilizada de forma general para realizar procesos de serialización y deserialización bidireccional entre objetos nativos de Java y su representación equivalente en JSON. Es necesario descargar su fichero JAR (por ejemplo, la versión 2.10.1) e incluirlo directamente en el Java Build Path (librerías externas) de nuestro proyecto.

2. Serialización: De Objeto Java a JSON

Para realizar la conversión directa de un objeto Java hacia formato JSON, basta con instanciar un objeto de la clase Gson y ejecutar su método toJson(). Sin embargo, esta salida genera todo el texto condensado en una sola línea sin espacios. Para obtener una salida estética y legible con sangrías e indentaciones correctas, se debe habilitar el Pretty Printing utilizando GsonBuilder.

Código: Serialización Básica y Pretty Printing
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;

// Serialización simple en una línea
Gson gson = new Gson();
System.out.println(gson.toJson(empleado));

// Serialización formateada estéticamente (Pretty Printing)
Gson prettyGson = new GsonBuilder().setPrettyPrinting().create();
System.out.println(prettyGson.toJson(empleado));

Personalización de Etiquetas: Si se desea forzar un nombre concreto para el atributo dentro del documento JSON resultante, diferente al de la variable en Java, se puede utilizar la anotación @SerializedName("nuevo_nombre") directamente sobre el campo de la clase.

3. Deserialización: De JSON a Objeto Java

El proceso inverso emplea el método fromJson(String, Clase.class), el cual toma como entrada la cadena JSON en bruto y la clase objetivo, mapeando automáticamente los valores siempre que los atributos del JSON coincidan con los de la clase base.

Código: Deserialización Estándar de un Objeto
import com.google.gson.Gson;

String json = "{\"nombre\":\"Pepe\", \"apellidos\":\"Lopez\", \"edad\":20}";
Gson gson = new Gson();
// El texto JSON se mapea y convierte automáticamente a una instancia de Empleado
Empleado emp1 = gson.fromJson(json, Empleado.class);
System.out.println(emp1.toString());
4. Manejo de Colecciones y Múltiples Objetos

Serializar Listas: Se puede inyectar directamente un ArrayList al método toJson(), y Gson se encargará de generar un array JSON (representado entre corchetes []) iterando sobre sus elementos.

Deserializar Listas: Para leer un array JSON de vuelta a una colección estructurada (List<Empleado>), Gson requiere conocer específicamente el tipo parametrizado genérico que va a contener la lista. Para lograr esto, se hace uso de la clase TypeToken.

Código: Deserializar dinámicamente un Array JSON a una Lista de Objetos
import com.google.gson.reflect.TypeToken;
import java.lang.reflect.Type;
import java.util.List;

// 1. Obtener y asegurar la estructura del Type de la lista utilizando TypeToken
Type tipoListaEmpleados = new TypeToken<List<Empleado>>() {}.getType();

// 2. Ejecutar la deserialización pasando el Type como segundo parámetro
List<Empleado> empleados = gson.fromJson(jsonArrayString, tipoListaEmpleados);

// 3. Iterar sobre la colección resultante
for (Empleado emp : empleados) {
    System.out.println(emp.toString());
}

Código: Serializar dinámicamente un ArrayList de Objetos a JSON
public static void ArrayToJSON() {
ArrayList<Empleado> empleados = new ArrayList<Empleado>();

Empleado emple1 = new Empleado("Pepe", "Lopez", 20, Arrays.asList("Gerente", "Jefe de zona"));
Empleado emple2 = new Empleado("Maria", "Gutierrez", 30, Arrays.asList("Jefe de RR.HH"));

empleados.add(emple1);
empleados.add(emple2);

Gson prettyGson = new GsonBuilder().setPrettyPrinting().create();
System.out.println(prettyGson.toJson(empleados));
}

Lectura y Escritura de Ficheros JSON mediante Flujos (Streaming)

1. Lectura con JsonReader

Se utiliza la clase JsonReader envolviendo un flujo de entrada (por ejemplo, FileInputStream con codificación UTF-8). Permite recorrer la estructura del documento de forma secuencial, abriendo arrays con beginArray() y procesando cada objeto de forma iterativa comprobando el avance con hasNext().

Código: Lectura de fichero JSON (JsonReader)
public static void JSONReaderFile() {
    Gson gson = new Gson();
    try {
        InputStream fis = new FileInputStream("empleados.json");
        JsonReader reader = new JsonReader(new InputStreamReader(fis, "UTF-8"));
        
        // Iniciamos la lectura del array principal
        reader.beginArray();
        
        // Iteramos mientras haya elementos en el array
        while (reader.hasNext()) {
            // Deserializamos el elemento actual directamente al objeto Empleado
            Empleado emp = gson.fromJson(reader, Empleado.class);
            System.out.println(emp.toString());
        }
        
        reader.close();
    } catch (IOException e) {
        e.printStackTrace();
    }
}
2. Escritura con JsonWriter

La clase JsonWriter permite construir un fichero JSON paso a paso escribiendo secuencialmente en el flujo de salida. Se moldea la estructura controlando las aperturas y cierres mediante llamadas explícitas a los métodos beginArray(), beginObject(), name() y value().

Código: Escritura de fichero JSON (JsonWriter)
public static void JSONWriterFile(ArrayList<Empleado> empleados) {
    try {
        JsonWriter writer = new JsonWriter(new FileWriter("workers.json"));
        
        writer.beginArray(); // Inicia el array principal de empleados
        
        for (Empleado emp : empleados) {
            writer.beginObject(); // Inicia un objeto empleado
            
            writer.name("nombre").value(emp.getNombre());
            writer.name("apellidos").value(emp.getApellidos());
            writer.name("edad").value(emp.getEdad());
            
            // Sub-array para la lista de puestos del empleado
            writer.name("puestos");
            writer.beginArray(); 
            for (String puesto : emp.getPuestos()) {
                writer.value(puesto);
            }
            writer.endArray(); // Fin del array de puestos
            
            writer.endObject(); // Fin del objeto empleado
        }
        
        writer.endArray(); // Fin del array principal de empleados
        writer.close();
        
    } catch (IOException e) {
        e.printStackTrace();
    }
}
